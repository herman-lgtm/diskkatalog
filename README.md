# Diskkatalog

En sökbar katalog över dina externa diskar för Mac. Sök efter filer, hitta dubbletter och se vad som bara finns på en enda disk, även när diskarna inte är inkopplade. Appen ändrar aldrig något på diskarna.

**[Ladda ner senaste versionen](https://github.com/herman-lgtm/diskkatalog/releases/latest)** (filen som slutar på `.dmg`)

- Kräver macOS 13 (Ventura) eller senare, Apple Silicon eller Intel.
- Finns på svenska, engelska, norska, danska, finska, tyska, nederländska, franska, spanska, italienska, portugisiska och polska.
- Appen uppdaterar sig själv: Inställningar › Sök efter uppdatering.

Första gången säger Macen att appen inte kan kontrolleras. Öppna då Systeminställningar › Integritet och säkerhet och klicka på **Öppna ändå**. Det behövs bara en gång.
